# Preserved license texts

This directory preserves license texts and related notices for upstream
projects and external dependencies referenced by
ShaguTweaks-Extras-ClassicAPI.

Files stored here are documentary copies. Their presence does not automatically
apply every listed license to the ShaguTweaks-Extras-ClassicAPI repository as a
whole.

- `ShaguTweaks-extras-MIT.txt` — original MIT license preserved from this
  fork's upstream/root `LICENSE`.
- `ShaguTweaks-mods-MIT.txt` — MIT license for the adapted
  TokensWorth/ShaguTweaks-mods material documented in
  `THIRD_PARTY_NOTICES.md`.
- `ShaguTweaks-ClassicAPI-MIT.txt` — license notice from the required external
  ShaguTweaks-ClassicAPI addon. That addon is not bundled here.
- `ClassicAPI-GPL-3.0.txt` — verbatim license document from the required
  external ClassicAPI repository. ClassicAPI is not bundled here.
- `SuperWoW-LICENSE.txt` — verbatim upstream license from the optional
  external SuperWoW repository. SuperWoW is not bundled here.

See `../THIRD_PARTY_NOTICES.md` for scope and provenance details.
